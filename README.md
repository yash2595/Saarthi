# Saarthi – MantraSetu AI Voice Assistant

Saarthi is an AI-powered multilingual voice assistant for Hindu rituals,
connecting users with pandits and providing real-time puja guidance.

## Stack
- **Backend**: FastAPI + MongoDB Atlas + Groq LLM + InWorld STT/TTS
- **Frontend**: React + Vite + TypeScript
- **AI**: Gemini, Groq (Qwen/GPT-oss), InWorld AI
